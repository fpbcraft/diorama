# Web cloud borders

Unknown and pending surface terrain is covered by animated clouds using the in-game fog shader, deterministic noise and conservative rounded borders. Nether and ceiling dimensions have no cloud layer. Clouds stay below players and overlays and do not intercept input.

A 64×64 coverage PNG accompanies every terrain tile, including overview tiles. Coverage comes from rendered alpha, never terrain colour: dark blocks remain known. Missing masks remain unknown. Startup repairs older masks in bounded background batches: existing depth sidecars recover coverage where possible; otherwise only affected base tiles enter the normal render queue. Existing JPEGs remain available, and overview coverage is rebuilt once. Busy ticks and saves defer repair. Do not delete tiles to repair clouds.

Coverage requests use the tile manifest independently of terrain image downloads. Cached masks survive zoom changes, with coarse coverage underneath finer masks while they load. Rounded borders also apply at far zoom. Newly arriving coverage reveals over 800 ms; changing zoom does not replay discovery. Reduced motion skips the transition and freezes drift. Background pages pause rendering.

Mask calculations run in a module worker, coalescing camera changes to the latest pending view. Cloud rendering has its own pixel budget independent of device pixel ratio: about 90,000 pixels and eight updates per second on touch devices, 180,000 pixels and 15 updates per second otherwise. Both drawing and mask preparation respect that rate during gestures. CSS reprojection keeps the existing layer aligned between frames. Terrain and vehicle rendering retain their own update rates. Unsupported workers fall back to main-thread mask calculation; unavailable/lost WebGL contexts use a Canvas mask.

Isolated Java/JavaScript checks cover legacy repair, independent web scope, overview holes, rounded coverage, worker coalescing, camera reprojection and pixel limits. The browser fixture checks reveal pixels, workers, a tablet-size touch viewport, Nether suppression, overlays and reduced motion. Actual Safari/iPad performance and the in-game visual comparison still require device testing; these checks are not a benchmark.
